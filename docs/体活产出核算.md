# 175级单号全天在线 · 体活产出核算（已核实 2026-10-31）

> 用途：管家随时可答的口径库。你问「175号一天产出多少」「海马收益多少」直接报这里的数据。
> 来源：用户资料 + 对照网易官方恢复公式核实（上限×1%取整 + 等级×2%取整 + 2，每5分钟恢复一次）。

## 条件（固定口径）
- 1500 体活（体力和活力上限均 1500）、175 级、186 符（临时符 186 级卖 4W/张）
- 体力价值：40 点 = 0.3W（书店卖体）
- 海马（每天限 1 个）、百岁香 120 品（每天限 1 个）、福祉豪宅满环境满卧室佣人
- 点卡 0.6 元/小时 → 14.4 元/天
- 藏宝阁比例 0.077 元/万（用户口径；悬浮窗白云山行情为 0.07467，两者差约 3%）

## 官方恢复公式核对
- 每5分钟恢复 = 上限×1%(取整) + 等级×2%(取整) + 2
- 175级/1500上限 = 15 + 3 + 2 = **20 点/5分钟** → 240 点/小时 → **5760 点/天**（24h 在线不溢出）
