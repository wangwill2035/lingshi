# 梦幻西游灵饰经营工作台 · 原生C++单文件应用技术文档

## 一、背景与目标
### 1.1 核心要求（用户明确约定）
- **纯原生C++实现**：单exe文件，无任何加壳、无脚本解释器、无浏览器内核、无运行时依赖
- 静态编译打包，拷贝到任何Windows电脑直接双击运行，不需要装VC运行库、不需要装SQLite、不需要装Python
- 启动毫秒级，内存占用<50MB，常驻后台无感知
- 替代现有「Python HTTP服务 + HTML浏览器」架构，彻底解决启动链路长、浏览器依赖、进程残留问题
### 1.2 功能范围（和现有工作台1:1对齐）
1. 扫码登记输入框（扫码枪直输，自动聚焦）
2. 四类操作支持：I入库/O上架/C中途盘点/E日结盘点，结构化逐行明细弹窗
3. 数据卡片展示：今日已售/已回款/未回款/在售总件数
4. 双矩阵展示：即时在售4×4、即时库存4×4
5. 回款登记输入，自动计算未回款
6. SQLite本地数据库原生读写，和现有mhxy.db表结构100%兼容

## 二、技术栈选型（纯原生，无任何套壳）
| 层 | 技术选型 | 说明 |
|----|----------|------|
| UI框架 | **Win32 API 原生控件** | 直接调用系统user32.dll，使用标准控件（Edit/Button/Static/ListBox/Tab），不做自绘，不依赖MFC/Qt/WTL |
| 图形绘制 | GDI+ | 系统原生绘制，不需要外部图形库 |
| 数据存储 | SQLite 3（C源码直接编译进exe） | 把sqlite3.c/sqlite3.h静态链接进二进制，不依赖外部sqlite.dll |
| 编译方式 | MSVC 静态MT编译 | 链接时静态链接C运行库，产物单文件，无外部dll依赖 |
| 单文件大小 | 预计~200KB | 纯Win32+SQLite静态链接，无冗余资源 |
| 运行依赖 | 0 | Win7及以上系统原生支持，不带任何运行库 |

**禁止项**：不用Python、不用Electron、不用WebView、不用Qt、不用MFC、不用任何第三方壳/解释器。

## 三、架构设计
```
灵饰工作台.exe（单文件）
├─ Win32 主窗口
│  ├─ 顶部：今日数据卡片区（4个Static文本块）
│  ├─ 左侧：扫码登记输入框 + 登记按钮 + 回款登记区
│  ├─ 中部：双矩阵Tab页（在售矩阵/库存矩阵）
│  ├─ 右侧：明细展示ListBox
│  └─ 弹窗：操作结果结构化明细（原生Dialog弹窗）
├─ 业务逻辑层
│  ├─ 二维码解析模块（parse_qr逻辑C++重写）
│  ├─ 四类操作逻辑（I/O/C/E业务规则）
│  ├─ 汇总计算模块
│  └─ 数据读写层（原生调用SQLite API）
└─ 数据文件：同目录mhxy.db（兼容现有数据库文件）
```
---

## 四、关键实现点
1. **扫码枪输入处理**：扫码输入框接收输入，回车触发解析，不用全局钩子，窗口获焦自动聚焦扫码框，和现有体验一致
2. **结构化弹窗**：操作完成后弹原生Dialog，用ListBox逐行显示明细，替代现在的HTML弹窗
3. **数据兼容**：直接打开现有mhxy.db文件，表结构完全沿用，不用迁移数据
4. **生命周期**：单进程单窗口，关窗口就退出，没有后台残留进程
5. **启动速度**：纯Win32窗口创建<100ms，双击秒开
